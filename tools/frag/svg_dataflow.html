1. SourceReal: data/raw/<scene>/obsmat.txt (ETH Walking Pedestrians via OpenTraj). Sim: CrowdSim.reset/step in foresight/domains/crowd.py.
  2. Tracks (INTERFACE.md)eth_ucy.convert() or crowd.generate() + save() write tracks.csv, obstacles.csv, meta.json. schema.load()/validate() checks columns, dt grid, duplicates, one ego, speed ≤ 5 m/s.
  3. Sensingfeatures.build_rows(): Gaussian noise per agent from rng([seed, agent_id]) (sd 0.1 m sim, 0 real), then the forward Kalman filter _kalman_cv(q, r) with (q, r) from kalman.json.
  4. RowEvery 0.5 s per person with a gap-free history window, one row per horizon: 39 numbers in the person's own frame (feature_names()).
  5. Target and labelsddx, ddy = deviation from the walk-straight point; mode, regime, since_switch as meta columns, never inputs (X_of()).
  6. Cache and userun_offline.rows_for() writes rows_f4_noise…_h…_kq…_kr….parquet; experiments read the cache, the closed loop builds the same rows live (run_closed.py).
